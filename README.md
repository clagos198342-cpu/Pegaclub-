# PegaClub – Encuentra tu pega, en comunidad

PegaClub es una comunidad digital para conectar personas con oportunidades laborales, compartir ofertas de trabajo y apoyarse en la búsqueda de empleo.

## Qué queremos construir
- Perfiles para que las personas se presenten y destaquen sus habilidades.
- Publicación y descubrimiento de ofertas laborales.
- Comunidad para compartir datos, recomendaciones y oportunidades.
- Herramientas para que empresas y reclutadores encuentren talento.

## Nuestro propósito
Hacer que encontrar trabajo sea más cercano, colaborativo y accesible.

## PegaClub
Una comunidad que conecta talento con oportunidades.
